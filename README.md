# PriNikki — Chocolate & Gifting Website

A responsive Django website with an editable homepage, product catalogue, product image uploads, categories, scheduled announcements, gift hamper promotions, contact form, WhatsApp enquiry links, testimonials, and Django admin management. Configured for deployment on Render.

## Features

- Premium responsive homepage and chocolate-inspired styling.
- Django admin at `/admin/` to manage website settings, products, categories, announcements, testimonials, and enquiries.
- Product image plus two optional gallery images; pricing can be omitted for price-on-request products.
- Product search, category filtering, sorting, pagination, and product details.
- Announcements can be published now or scheduled with start/end times and displayed in the top bar, homepage, or both.
- Contact details and WhatsApp number are editable under **Website settings**.
- Contact enquiries are stored in the database and visible in admin.
- Static files served by WhiteNoise; PostgreSQL supported through `DATABASE_URL`.
- Optional Cloudinary image storage for persistent uploaded images on Render.

## Run locally

Requires Python 3.12 or newer.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate --run-syncdb
python manage.py createsuperuser
python manage.py runserver
```

Open `http://127.0.0.1:8000/` for the website and `http://127.0.0.1:8000/admin/` for management. On first login, create one **Website settings** record. The admin is intentionally the content-management interface; no code edits are needed for ordinary updates.

## Deploy to Render

1. Push this project to a GitHub repository.
2. In Render, choose **New + → Blueprint** and connect the repository. Render reads `render.yaml` and provisions the web service and PostgreSQL database. The included database plan may require a paid Render plan; adjust the plan to one available in your account.
3. Add `CLOUDINARY_URL` to the web service environment using the connection URL from your Cloudinary account. This is strongly recommended: Render's ordinary filesystem is ephemeral, so uploaded images stored locally can disappear on redeploy/restart. If you do not want Cloudinary, configure a persistent disk and use a suitable media path, or use another durable object-storage backend.
4. Deploy and wait for the build to complete.
5. In the Render dashboard, open the web service **Shell** and run:

   ```bash
   python manage.py createsuperuser
   ```

6. Visit `https://YOUR-SERVICE.onrender.com/admin/`, sign in, and create the Website settings record.
7. Upload the logo/hero image if desired, enter your real phone and WhatsApp numbers, then add categories and products. Publish products and announcements when ready.

### Render environment variables

- `SECRET_KEY`: generated by the Blueprint.
- `DEBUG=False`: production mode.
- `ALLOWED_HOSTS`: `.onrender.com` is included by default. Add your custom domain if needed.
- `DATABASE_URL`: injected by the Render database resource.
- `CLOUDINARY_URL`: optional at deploy time, recommended before uploading real product images.

## Admin workflow

1. **Website settings** — create the single settings record, add phone/WhatsApp/email and update homepage copy.
2. **Categories** — add categories and optional category photos; mark active.
3. **Products** — add products, upload images, set price if applicable, tick `Published` and `Available` to show them publicly.
4. **Announcements** — add a gift hamper or launch announcement, upload an image, set start/end times, select display location, and tick `Published`.
5. **Testimonials** — only approved testimonials appear; feature them to show on the homepage.
6. **Enquiries** — review contact-form messages and update their status.

## Important notes

- The starter version supports WhatsApp-based product enquiries rather than a cart/payment checkout. No payment gateway is represented as integrated.
- Configure the WhatsApp number with digits only, including country code, for example `919876543210`. The phone display field can contain spaces or `+`.
- Product prices are displayed in INR when entered. Keep price blank to show “Price on request.”
- All date/time scheduling uses the `Asia/Kolkata` timezone.
- Use real product photography and genuine testimonials before public launch.
- Before production, review privacy wording, terms, delivery/returns policy, and business details for your actual business.
